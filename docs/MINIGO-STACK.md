# Fromago + Minigo (enquêtes)

Fromago reste un thème formulaires autonome. Pour une vitrine produit Lowdit avec vue **inquiry** :

```toml
theme = ["minigo", "fromago"]

[params.lowdit]
  siteProfile = "inquiry"
  view = "inquiry"
```

Synchroniser la marque : `lowdit-brand/scripts/sync-brand.sh themes/minigo`.
